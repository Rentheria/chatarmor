# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in ChatArmor, please report it responsibly:

1. **GitHub Security Advisories** (preferred): [Report a vulnerability](https://github.com/Rentheria/chatarmor/security/advisories/new)
2. **Email**: Send details to the maintainer via the email listed in [package.json](./package.json)

Please **do not** open a public issue for security vulnerabilities.

## What to Include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fixes (optional)

We will acknowledge your report and work on a fix. Security fixes are released as soon as possible.

## Política de Seguridad

### Reportar una Vulnerabilidad

Si descubres una vulnerabilidad de seguridad en ChatArmor, repórtala de forma responsable:

1. **GitHub Security Advisories** (preferido): [Reportar vulnerabilidad](https://github.com/Rentheria/chatarmor/security/advisories/new)
2. **Email**: Envía detalles al maintainer al email listado en [package.json](./package.json)

Por favor, **no** abras un issue público para vulnerabilidades de seguridad.

### Qué Incluir

- Descripción de la vulnerabilidad
- Pasos para reproducirla
- Impacto potencial
- Soluciones sugeridas (opcional)

Reconoceremos tu reporte y trabajaremos en una solución. Los fixes de seguridad se publican lo antes posible.
